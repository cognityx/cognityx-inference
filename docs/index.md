# LLM Benchmark

`llm-benchmark` is an interactive local-model benchmark harness for repeatable,
long-context inference experiments. It keeps a selected model resident, streams
generated text, records timing and memory diagnostics, separates reasoning from the
final answer, and saves structured JSON results.

## Capabilities

- Persistent Transformers and optional isolated vLLM engines.
- BF16, FP16, BitsAndBytes INT8/INT4, and checkpoint-native quantization paths.
- Configurable long-context corpora with exact token budgeting.
- Time-to-first-output, throughput, token counts, GPU memory, prefix-cache, and
  model-runtime diagnostics.
- Repeatable `/benchmark` runs, interactive parameter changes, result comparison,
  and safe request cancellation.
